# 如窗 1.2(1) 更新说明

**发布日期**：2026-07-25  
**版本号**：`1.2(1)`（`CFBundleShortVersionString = 1.2`，`CFBundleVersion = 1`）  
**安装包**：`LikeWindows-1.2(1).dmg`（由 `scripts/build-dmg.sh` 生成）

相对上一版 `1.1` / 基线 `e2a262a`，本版本聚焦后台入口、悬停体验与多窗行为边界。

---

## 新增

### 菜单栏常驻入口

- 关闭偏好设置后，应用以后台（`.accessory`）常驻。
- 菜单栏新增「如窗」图标，可随时打开偏好设置或退出应用。
- 偏好设置增加「菜单栏图标」开关（默认开启）。
- 说明：系统设置侧栏无法接入第三方应用，菜单栏为等价入口。

### Dock 悬停探测（DockDoor 式）

- 新增 `DockAXHoverProbe`：订阅 Dock `AXSelectedChildren`，替代纯坐标扫描驱动弹窗。
- 首次悬停约 **0.2s** 延迟后再弹出，减少快速划过误触。
- 鼠标移入自绘弹窗后保持展示（SelectedChildren 清空不关窗）。

---

## 改进

### 快速显示/隐藏

- **仅单窗口**应用拦截 Dock 点击做最小化/恢复。
- **多窗口**应用不再拦截 Dock 点击（交给系统）；窗口切换请用悬停标题列表。
- 去掉多窗 Dock 点击「全部最小化」行为。

### Dock 信息弹窗

- 列表行悬停高亮改为互斥选中（进入新行直接覆盖），减轻粘滞与跟手差。
- 弹窗内切窗改为更轻量的激活路径，减轻 Chrome 等多窗切换闪烁。
- 标题行点击：当前前台焦点窗再点则最小化，否则激活。
- 去掉列表级 AppKit `mouseMoved` 双轨命中，降低悬停时 CPU 开销。
- Probe 同目标不再重复通知；鼠标路径优先用缓存，兜底轮询再强制读 AX。

### 打包与版本

- 应用内关于页显示 `1.2 (1)`。
- DMG 文件名改为 `LikeWindows-1.2(1).dmg`（含 build 号）。

---

## 产品边界（本版确认）

| 做 | 不做 |
|----|------|
| 单窗快显/隐藏 | 多窗 Dock 全最小化 |
| 多窗自绘标题列表 | DockDoor 式截图预览 |
| 菜单栏入口 | 系统设置侧栏入口 |
| SelectedChildren 悬停生命周期 | 模拟按键触发系统 Exposé |

---

## 使用提示

1. 首次使用请授予**辅助功能**权限。
2. 关闭偏好设置窗口后应用不会退出，请从**菜单栏图标**再次打开。
3. 多窗口应用：悬停 Dock 图标打开列表，再点标题切换；直接点 Dock 走系统行为。
